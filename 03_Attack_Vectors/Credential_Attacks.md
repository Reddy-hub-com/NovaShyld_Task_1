Credential Attacks

Credential attacks target usernames and passwords to gain unauthorized access.

Common Methods
Brute Force
Password Spraying
Credential Stuffing

Technique	ID	Description
Brute Force	T1110	Attempts multiple passwords

MFA
Account lockout
