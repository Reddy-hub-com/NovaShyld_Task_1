Phishing
Description

Phishing is a social engineering attack where attackers send fraudulent emails, messages, or websites to trick users into revealing sensitive information or executing malicious files.

Common Objectives
Steal usernames and passwords
Deliver malware
Gain initial access to a network
MITRE ATT&CK Mapping
Technique	ID	Description
Phishing: Spearphishing Attachment	T1566.001	Malicious email attachment
Phishing: Spearphishing Link	T1566.002	Malicious URL in email
Phishing via Service	T1566.003	Messages through trusted services
Prevention
Email filtering
Multi-Factor Authentication (MFA)
Security awareness training
URL and attachment scanning
